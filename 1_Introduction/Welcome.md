
# Welcome to Live Agile

Live Agile is a human‑centred framework for navigating work, life, and long-term direction with clarity and compassion.
It brings together seasonal intention, weekly rhythm, and daily awareness, creating a structured yet gentle way of moving through complexity.

This site serves as:
- A reference guide for practitioners.
- A facilitator’s manual for leading Live Agile Seasons.
- A knowledge base that will later support an AI facilitator within Communi.Team.

Live Agile is not a productivity system.
It is a **presence system**.
